## Usage in the desktop

- `ironbark-night.jpg` renders in the left sidebar (quiet surface, original
  aspect preserved via `object-fit: cover` on a bounded strip) and as the
  quiet new-chat welcome surface.
- `ironbark-lock.jpg` renders only as the sidebar ambient image on the
  conversation surface.
- Artwork is never placed behind working text, code, logs, forms or approval
  details; no bark texture sits under any interactive content.

## Rights gate

Local preview use of these files is approved by the design direction.
Redistribution in a packaged build remains gated on an explicit
artwork rights/attribution disposition (plan D5); that gate is not cleared by
this copy and no package ships these assets until the disposition lands.
