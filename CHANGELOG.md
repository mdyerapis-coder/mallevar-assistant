# Changelog

## Unreleased

- Release gates now require exact-source v2 receipts: pre/post/current commit and product-byte inventory, toolchain executables, literal argv/cwd and the delivered environment must match. Separate 64 KiB stdout/stderr rings record original/dropped bytes without collecting full output. Real runner/checker CLI smoke covered nine passing/refusal scenarios; review-discovered environment, automatic Cargo/Bun configuration and private-dotenv bypasses have failing-before/passing-after regressions. Existing eight release gates are unchanged; no full joined release is claimed.
- Ordinary harness discovery tests now use private real executable fixtures rather than installed operator CLIs. Version failure, malformed initialization, route mismatch, probe timeout and owned-process cleanup remain observable without native authentication; opted-in live qualification remains separate.
- Native ACP now streams partial output before completion, denies permissions when no reject option exists, and waits for the real cancellation response. Full session identity is pinned independently of mutable returned references; missing/unknown/refusal/budget stop reasons cannot become success. Native EOF rejects every pending RPC as disconnection rather than waiting for fabricated request timeouts. Real two-turn executable smoke preserved the same native process between cancellations and observed its exit on close; this does not implement core resumable `run_interrupt`.
- Backup, restore and retention share one closed schema-1 reference registry. Typed owned references replace JSON-key guessing, so literal text and external identity/content hashes are not mistaken for CAS objects; unknown schema/reference forms refuse deletion. Current positive storage/ingest/workspace targets passed 60 tests, and actual CLI backup/stopped restore preserved source/checkpoint bytes, blocked restored work and rejected missing/corrupt objects before installation.
- Fixed selective JEV calibration: score ties are indivisible, unsafe groups do not leak into receipt counters, and attempted/available/selected counts remain distinct by class. The CLI emits a digest-bound v2 diagnostic artifact and imports without running inference. A real isolated CLI smoke changed from an incorrect 21-selected/21-attempted result to 19-selected/22-attempted; no live domain or signed review freeze is qualified by that fixture.
- Fixed live JEV qualification plumbing: calibration/evaluation now share the actual client's strict identity probe rather than requesting the facade's nonexistent `/health` route and computing a different identity digest. Runtime discovery follows only the facade's exact numeric-loopback local endpoint, binds that endpoint into the identity, and accepts llama.cpp's observed string quantization metadata.
- Fixed holdout class accounting: fixture validation reads the stored top-level `class`, not nonexistent `meta.class`, and rejects unknown classes. Holdout reports retain per-row outcome evidence and reject accepted choices from a different runtime identity.
- Verified the actual local JEV classification path against Qwen2.5-0.5B-Instruct-Q8_0 (`b11559-f2cc7282c`): `REVIEW`, 432 ms. Final focused verification: 44 adapter tests, 13 native qualification tests and a clean `bunx tsc --noEmit`.
- Corrected TypeScript and Rust binomial CDF arithmetic against independent exact-combinatorial reference bounds, including high-error and 2,000-observation tails. Fixed core persistence rejecting honest wrong-answer reports by double-counting `wrong_accepted` inside `accepted`.
- Quarantined the full 1,000-calibration/1,000-holdout synthetic diagnostic run: all five domains blocked; independent review found repeated content crossing splits and inverted labels. Dataset validation now rejects duplicate content and IDs across all fixture files, and dataset digests cover validated payloads. Removed size-only fixture assertions that had passed this invalid dataset.

Actual extracted core/CLI binaries from each passed isolated status, wrong-answer report persistence as Blocked, restart/readback and shutdown; both desktop files validated. RPM build/smoke used Arch, not a Fedora installation. No upstream upload, tag replacement, GUI qualification or main merge occurred.
